# Design System

本文档定义「财记」的统一视觉标准，作为 Dashboard 与其他页面迭代时的基线。

## 1. 产品气质

- 定位：本地优先的个人资金管理工具，不是演示站。
- 关键词：克制、清晰、长期可用、金融感。
- 视觉方向：香槟金 + 纸白 + 墨色文本，强调信息而非炫技。

明确不做：

- 不做科技蓝主导风格。
- 不做高饱和土豪金。
- 不做黑金夜店风。
- 不做重动画干扰阅读。

## 2. 色彩规则

### 主色与语义色

- 主点缀：`--primary` / `--primary-dark`，用于强调边框、重点数字、核心按钮。
- 背景层：`--bg`、`--surface`、`--surface-soft`、`--paper-glass*`，用于页面与卡片层次。
- 文本层：`--text`（主文本）与 `--muted`（辅助说明）。
- 状态色：
  - 正向：`--success`
  - 警示：`--warning`
  - 负向：`--danger`

### 禁止项

- 不使用绿色作为全局主视觉。
- 不使用高饱和纯金块面。
- 不让视觉效果压过数据可读性。

## 3. 设计 Token 使用原则

- 阴影统一使用 `--shadow-xs/sm/md/lg`，禁止新增随意阴影值。
- 圆角统一使用 `--radius-sm/md/lg/pill`，避免同类组件出现多套圆角。
- 线条统一使用 `--line` / `--champagne-line`。
- 旧变量兼容仅保留过渡用途，新增代码不再依赖旧命名。

## 4. 字体规则

- 正文与表单：无衬线，优先可读性。
- 品牌与视觉标题：可局部使用中文衬线增强气质。
- 数字：统一 `--font-number`，并开启 `tabular-nums` 保证对齐。
- 小字号信息（标签、表格、注释）禁止使用过细字重。

## 5. Dashboard 结构规则

Dashboard 是“财记”的主界面，结构保持稳定：

1. 顶部状态条：日期、快捷操作、保存状态。
2. 主体三列：左侧资产卡、中部中枢视觉、右侧状态卡。
3. 底部两层：数据带 + 导航状态条。

禁止将 Dashboard 退化为“普通后台卡片堆叠”。

## 6. 组件规则

### 卡片

- 轻玻璃质感 + 柔和边框。
- 阴影轻，不做厚重悬浮。

### 按钮

- 主按钮强调结构与可识别性，不做高饱和色块。
- 次按钮弱化处理，但保持可点击感。
- 危险按钮仅用于风险动作。

### 标签 / 进度 / 图表

- 标签语义必须与状态色一致。
- 进度条优先使用账户色或主色，风险状态可用 `--danger`。
- 图表服务于理解，避免复杂装饰。

### 弹窗 / 表单

- 弹窗层次清晰、遮罩克制。
- 表单强调录入效率，禁用复杂背景干扰。

## 7. 动效规则

- 仅允许轻量交互动画（hover、淡入、状态过渡）。
- 禁止大范围旋转、粒子、强闪烁等干扰动效。
- 动效不能影响录入与读数稳定性。

## 8. 开发守则

- 所有视觉改动必须优先复用现有 token。
- 不允许先改结构后补规范说明。
- Dashboard 改动必须说明影响范围并做截图回归。
- 逐步演进，不做无验证的大规模样式迁移。
