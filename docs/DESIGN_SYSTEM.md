# Design System

本文档记录财富志当前和后续应遵守的视觉方向，用于 dashboard 视觉复刻、其他页面统一和商业化准备。

## 1. 设计定位

财富志是一个本地优先的私人资金管理网页应用。

目标气质：

- 香槟金金融座舱
- 私人财富驾驶舱
- 克制、高级、清晰、有工具感
- 面向长期使用，而不是一次性展示页

明确不做：

- 不做普通后台管理系统
- 不做甜美手账风
- 不做科技蓝大屏
- 不做过度装饰的炫技页面

## 2. 色彩规则

### 主色和用途

- 金色 / 香槟金是主点缀色。
  - 用于边框、高亮、重点图形、主按钮细节、资产氛围。
  - 应该克制、柔和、偏香槟，不应刺眼。

- 绿色只用于状态描述。
  - 收益
  - 正常
  - 安全
  - 低风险
  - 已完成

- 红棕用于负向状态。
  - 亏损
  - 风险
  - 超支
  - 高风险
  - 需要关注的警告

- 石墨黑用于文字与结构。
  - 主文字、标题、重要数字、结构性按钮。

- 纸白 / 暖灰用于背景和卡片。
  - 页面背景、玻璃卡片、表单区、次级信息承载。

### 禁止项

- 禁止大面积绿色作为主视觉。
- 禁止土豪金、纯金块、大面积高饱和金色。
- 禁止科技蓝作为主视觉。
- 禁止黑金夜店风。
- 禁止为了视觉冲击降低数据可读性。

## 3. 设计变量建议

当前项目已有 CSS token，可继续沿用并逐步收敛。

| 用途 | 当前或建议 token | 说明 |
| --- | --- | --- |
| 页面背景 | `--bg` | 暖米色底，承接整体金融纸感。 |
| 主卡片 | `--surface` | 纸白卡片底色。 |
| 柔和卡片 | `--surface-soft` | 暖灰/柔米色，用于次级区域。 |
| 主文字 | `--text` | 石墨黑，保证可读性。 |
| 次文字 | `--muted` | 暖灰棕，用于说明和辅助信息。 |
| 主金色 | `--primary` | 香槟金主点缀。 |
| 深金色 | `--primary-dark` | 用于重点文字、深一点的金色强调。 |
| 柔金边框 | `--champagne-line` / `--line` | 卡片边框、分割线。 |
| 成功绿 | `--success` | 收益、正常、安全、完成。 |
| 风险红 | `--danger` | 亏损、风险、超支。 |
| 警告色 | `--warning` | 预算接近上限、待处理状态。 |
| 圆角 | `--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-pill` | 卡片不宜过圆，按钮和标签可使用 pill。 |
| 阴影 | `--shadow-xs`, `--shadow-sm`, `--shadow-md`, `--shadow-lg` | 保持轻柔，不制造厚重浮层。 |
| 玻璃拟态 | `--paper-glass`, `--paper-glass-strong` | 用于卡片和座舱区域，透明度应克制。 |

## 4. 字体原则

- 中文标题可以偏宋体 / 衬线感。
  - 用于品牌、dashboard 主视觉、重要标题。
  - 目标是稳重、私人财富感，而不是传统公文感。

- 数字应更金融、更优雅。
  - 可参考 Georgia、Cormorant、系统 serif 或金融感数字字体方向。
  - 当前项目已有 `--font-number`，后续可以继续统一数字显示。

- 正文保持清晰可读。
  - 表单、说明、记录列表优先使用系统 sans-serif。

- 不要为了高级牺牲可读性。
  - 小字号数字、表格、标签、按钮必须清楚。
  - 不使用过细、过窄、过装饰性的字体承载核心数据。

## 5. Dashboard 首页视觉规则

Dashboard 是香槟金金融座舱，不是普通统计面板。

结构原则：

- 顶部状态栏
  - 承载日期、状态、快捷入口和关键上下文。

- 左资产主卡
  - 承载资产总览、净值、趋势和关键资产指标。

- 中间财字中枢
  - 中心“财”字是主视觉资产。
  - 代表私人财富驾驶舱的核心精神资产。
  - 不应被普通图表或普通卡片替代。

- 右结构卡
  - 承载资产结构、风险、目标、备份等辅助判断。

- 底部双层
  - 第一层是数据带，用于横向展示关键数据和洞察。
  - 第二层是状态/导航控制台，用于页面切换和状态反馈。

禁止项：

- 不允许回到普通仪表盘堆卡片。
- 不允许把 dashboard 改成传统后台首页。
- 不允许让中心主视觉失去存在感。
- 不允许用大面积绿色或科技蓝重塑 dashboard。

## 6. 组件规则

### 卡片

- 使用纸白、暖灰、轻玻璃质感。
- 边框以柔金线为主。
- 阴影轻，不做厚重悬浮。
- dashboard 卡片可以更座舱化，但仍要保证数据清晰。

### 按钮

- 主按钮可以使用石墨黑到深灰的结构色，并带少量金色边缘或内光。
- 次按钮使用纸白/暖灰底和柔金边框。
- 危险按钮使用红棕，不使用高饱和红。
- 按钮文案必须清晰，不为装饰牺牲识别。

### 状态标签

- 正向状态使用绿色。
- 风险/亏损使用红棕。
- 警告/待处理使用柔金或暖黄。
- 标签应小而清晰，不要抢主视觉。

### 进度条

- 默认使用账户色或香槟金。
- 风险进度可使用红棕。
- 背景轨道使用暖灰/柔金低透明度。

### 图表

- 图表服务于理解，不做复杂炫技。
- 饼图、趋势图、迷你 sparkline 应保持轻量。
- 颜色优先服从账户色、香槟金、状态色规则。

### 弹窗

- 弹窗使用纸白或暖玻璃底。
- 遮罩轻，不要让页面产生强烈割裂感。
- 操作按钮保持明确层级。

### 表单

- 表单区域优先清晰、可扫描。
- 输入框使用暖灰底、柔金 focus。
- 不使用强装饰背景影响录入效率。

## 7. 动效规则

- 只允许微交互。
- hover 可以轻微上浮。
- 中心光效可以慢速呼吸。
- 状态变化可以柔和过渡。

禁止项：

- 禁止强粒子效果。
- 禁止强旋转。
- 禁止炫酷大动画。
- 禁止会干扰读数和录入的动效。
- 动效不能影响理财工具的稳定感。

## 8. AI 修改守则

- 修改视觉前必须先遵守本文件。
- 不允许擅自把绿色作为主视觉。
- 不允许擅自改成科技蓝、黑金、土豪金。
- 不允许为了炫酷牺牲可读性。
- Dashboard 视觉修改必须先说明范围。
- 不允许未经说明就重写 dashboard 首页结构。
- 不允许把香槟金金融座舱降级成普通后台卡片布局。
- 页面统一应渐进完成，不做大规模无测试 CSS 迁移。
